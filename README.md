# SQL Notes 📚

Una colección de apuntes, ejemplos y ejercicios sobre **SQL** y **Bases de Datos Relacionales**. Este repositorio está pensado como una referencia personal para consultar la sintaxis, conceptos fundamentales y consultas más utilizadas en SQL.

## 📖 Contenido

* Introducción a las bases de datos relacionales
* Consultas con `SELECT`
* Filtrado de datos (`WHERE`)
* Ordenamiento (`ORDER BY`)
* Eliminación de duplicados (`DISTINCT`)
* Búsquedas con `LIKE`
* Operadores lógicos (`AND`, `OR`, `NOT`)
* Rangos y conjuntos (`BETWEEN`, `IN`)
* Agrupación de datos (`GROUP BY`, `HAVING`)
* Expresiones condicionales (`CASE`)
* Manejo de valores nulos (`COALESCE`, `IFNULL`)
* Combinación de tablas (`JOIN`)

  * `INNER JOIN`
  * `LEFT JOIN`
  * `RIGHT JOIN`
* Unión de resultados (`UNION` y `UNION ALL`)

## 🎯 Objetivo

El propósito de este repositorio es documentar mi proceso de aprendizaje en SQL mediante notas claras, ejemplos prácticos y consultas comentadas. La idea es construir una referencia rápida que pueda consultar en el futuro.

## 💻 Motor SQL

Los ejemplos están escritos principalmente para **MySQL**, aunque la mayoría de las consultas siguen el estándar SQL y pueden adaptarse fácilmente a otros sistemas gestores de bases de datos.

## 🚀 Cómo usar este repositorio

1. Clona el repositorio.
2. Crea la base de datos de ejemplo.
3. Ejecuta los scripts SQL.
4. Sigue las notas y prueba cada consulta por tu cuenta.
